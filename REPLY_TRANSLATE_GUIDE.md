# 🌐 Reply-to-Translate Feature Guide

## ✨ New Feature!

Now you can **reply to ANY message** to translate it instantly!

---

## 🎯 How It Works

### **Method 1: Reply with /tr (Default: Hindi)**

1. **Reply to a user's message**
2. **Type `/tr`** (no language code needed)
3. **Bot translates to Hindi automatically!**

**Example:**
```
User1: Hello, how are you today?
You: [Reply] /tr
Bot: 🌐 Translation

   Original (User1's message):
   Hello, how are you today?

   Translated (🇮🇳 Hindi):
   नमस्ते, आज आप कैसे हैं?
```

---

### **Method 2: Reply with /tr <lang> (Specific Language)**

1. **Reply to a user's message**
2. **Type `/tr en` or `/tr es` etc.**
3. **Bot translates to your chosen language!**

**Examples:**
```
User1: Bonjour, comment allez-vous?
You: [Reply] /tr en
Bot: 🌐 Translation

   Original (User1's message):
   Bonjour, comment allez-vous?

   Translated (🇬🇧 English):
   Hello, how are you?
```

```
User1: Good morning everyone!
You: [Reply] /tr es
Bot: 🌐 Translation

   Original (User1's message):
   Good morning everyone!

   Translated (🇪🇸 Spanish):
   ¡Buenos días a todos!
```

---

### **Method 3: Reply with /tl (Language Menu)**

1. **Reply to a message**
2. **Type `/tl`**
3. **Select language from button menu**

**Example:**
```
User1: What a beautiful day!
You: [Reply] /tl
Bot: [Shows language selection buttons]

You: [Click 🇮🇳 Hindi]
Bot: 🌐 Translation

   Original: What a beautiful day!
   Translated (🇮🇳 Hindi): क्या खूबसूरत दिन है!
```

## 🐛 Troubleshooting

### **Bot doesn't respond to reply?**
- Make sure you're actually replying to the message
- Check if message has text (not just sticker)
- Verify bot has permission to read messages

### **Translation seems wrong?**
- Try a different target language
- Check if source text is clear
- Some slang may not translate perfectly

### **"Unsupported language" error?**
- Use `/langs` to see valid language codes
- Common codes: hi, en, es, fr, de, ru, zh, ja, ar
