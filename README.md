# titanic-saver

A powerful Telegram Group Help Bot built with `python-telegram-bot` (v21+).

## Features
- **Moderation**: Ban, Mute, Warn, Promote, and a custom Muter role.
- **Settings**: Interactive button-based menu for all group configurations.
- **Welcome/Goodbye**: Customizable greetings with HTML, media, and buttons.
- **Clean Service**: Automatic deletion of system messages.
- **Auto Delete**: Message self-destruction with custom timers.
- **Filters**: Custom trigger-based auto-replies.
- **Security**: Granular permission checks for settings access.
- **Styling**: Unique small caps (tiny text) font for all bot responses.
- **Auto-Cleanup**: Bot messages automatically delete after 2 minutes.
